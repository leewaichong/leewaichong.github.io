Privacy Policy

For fitb, last updated 28 August 2026.

fitb is a personal command-line tool written and used by Lee Wai Chong. It has one user: its author. It is not a product, it is not offered to anyone else, and it has no server.

What it accesses

Read-only access to the author's own Google Health data, via these scopes:

  • Activity and fitness (steps, distance, exercise sessions)
  • Sleep
  • Health metrics and measurements (weight, heart rate)

It requests no write access and cannot modify or delete anything.

Where the data goes

Onto the author's own computer, and nowhere else. There is no backend, no database, no analytics, and no third-party service. Nothing is transmitted anywhere except between that computer and Google's own API. Nothing is sold, shared, or disclosed, because there is nobody to share it with.

Retention

Access and refresh tokens are stored locally with owner-only file permissions. Health data is fetched on demand and kept only in local files the author creates. Deleting those files deletes the data.

Revoking access

Access can be withdrawn at any time from Google Account permissions, which immediately invalidates the tokens.
